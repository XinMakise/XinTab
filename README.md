# XinTab

XinTab 是一个面向 Chrome 新标签页的个人入口页扩展，聚合了常用网站入口、浏览器书签、最近访问、搜索与外观定制能力，让新标签页更适合作为日常起始页。
![XinTab 新标签页界面预览](image.png)

## 功能特性

- 手动导航分类、链接管理与拖拽排序
- Chrome 书签浏览、编辑、移动和删除
- 最近访问展示与快速加入导航
- 搜索引擎配置与搜索建议
- 顶栏、搜索栏、卡片、建议面板的外观与材质配置
- 数据导入导出与双栏快速编辑

## 安装

1. 下载 XinTab 的发布包
2. 解压到本地任意目录
3. 打开 Chrome，进入 `chrome://extensions/`
4. 打开右上角“开发者模式”
5. 点击“加载已解压的扩展程序”
6. 选择解压后的 XinTab 目录
7. 安装完成后，新建标签页即可使用

## 使用说明

- 在首页管理常用站点分类和链接
- 在书签页直接整理 Chrome 书签
- 使用搜索栏进行搜索，并按需要启用搜索建议
- 在设置面板中调整主题、透明度、材质与背景图
- 通过导入导出功能迁移个人配置数据

## 说明

- XinTab 主要面向 Chrome 新标签页场景
- 部分能力依赖 Chrome 提供的书签与历史记录 API
